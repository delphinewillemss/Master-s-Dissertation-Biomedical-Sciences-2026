# 🧬 Master's Dissertation Biomedical Sciences 2026–2027 

## Overview

This repository serves as an electronic lab notebook and code archive for my Master's Dissertation in Biomedical Sciences (Ghent University, 2026–2027).

The project focuses on the bioinformatic analysis of next-generation sequencing (NGS) data generated from mouse embryos using the mm10 reference genome. The broader aim is to investigate the genomic stability and safety of nuclear transfer technology by assessing chromosomal abnormalities, copy number variations (CNVs), and other genomic features.

This repository is continuously updated throughout the course of the research project and contains scripts, workflows, job files, analyses, and documentation used during data processing and downstream analysis.

---

## Research Background

Nuclear transfer is a technique in which the nucleus of a donor cell is transferred into an enucleated oocyte. While this technology has important applications in developmental biology and biomedical research, questions remain regarding its impact on genome stability during embryonic development.

To investigate this, sequencing data from mouse embryos are analyzed using a range of bioinformatic approaches, including alignment, quality control, genome-wide copy number analysis, and other downstream analyses as required throughout the project.

Reference genome:

- Mouse genome assembly: **mm10**
